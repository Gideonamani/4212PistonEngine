# Gear-train comparison before exterior work

The user requested an internal diagram and an OEM gap assessment before continuing casting contours or external systems. This review uses the accepted static drive package, unchanged. Local output: `build/gtsio520-geartrain-review/review.html`. Native diagram scenes and PNGs remain ignored; the source plans, assessment and validation evidence are tracked.

Figure A-4-8 has 25 schematic callouts. Eight are represented in our detailed engine: **1, 2, 3, 4, 5, 23, 24, 25**. Seventeen are missing: **6-22**. These are identity counts, not a percentage of engine completion or manufacturer accuracy. Key 3 represents two gear pieces; key 5 covers twelve eight-piece lifters, with only Exhaust3 displayed. The quill is mostly enclosed in the main assembled view; its isolated inset changes visibility only.

Read assessment.json for every OEM identity and its generated part IDs, the five missing modules, prerequisites, native modelling choices, relevant fixtures/checks, earlier methods we can reuse and suggested order. Effort is estimated in focused build/validation iterations; it is not an elapsed-time promise. The user narrowed the initial starter scope to its main-train shaftgear and supported shaft/interfaces, plus one simplified stationary shell. Worm, clutch and motor internals stay deferred; the initial starter task uses the tested spur method. A later genuine worm/wheel/clutch reconstruction remains a substantial separate task. The idler/magneto branch is the best first integration step after shared rear-axis and ratio research.

Additional work hidden by the overview matters: the cam gear currently has a plain bore rather than its oil/tach spline receiver; the compound idler needs its accessory wheel and support; pump gears need chambers, bearings and passages; the starter needs its complete adapter/retention/clutch assembly. The alternator face gear belongs on the **crankshaft** (A-4-20 keys21-23 and A-12-10, printed A-12-4 / PDF80), with its coupled driven gear and thrust/retaining parts. It must not be improvised on the propeller gear. The H fuel-pump replacement changes the gear/coupling/stud interface; resolve that variant before final geometry.

The OEM overview is a generic/basic schematic, supplemented here by the H difference data. It does not determine manufacturing tooth counts, modules, exact axial stations or hidden bores. H ratio constraints include magnetos 1.5, tachometer 0.5, alternator 3.0, vacuum accessories 1.14 and governor 0.809 relative to crank; starter/crank ratio is 32. The governor/cam ratio is consequently about 1.618. A confirmed 90-degree bevel pair would need unequal pitch cones near 58.3/31.7 degrees, not two default 45-degree gears. The eventual detailed starter total ratio also includes the final spur mesh; 32 total does not establish a 32-tooth worm wheel. The initial shell does not implement or validate that internal transmission.

FCGear documentation and bevel/worm/crown source were inspected as candidate implementation methods, not installed or adopted. Bevel/face/worm-wheel fixtures must prove save/reopen, parameter changes, STEP and compatible engagement before main-engine use. Its Python proxies also introduce a dependency to pin/carry, or a need to implement reviewed linked native profiles in our own backend. The old accessory study's worm deliberately clears a spur-like wheel; it cannot be promoted into a true mesh.
