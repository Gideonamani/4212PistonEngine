# Quiet Workshop

Optional two-minute excerpt from the project's original procedural score, used in the existing Blender videos. Source: `EngineSimulation/v5/Original_Quiet_Workshop_Score.wav` in the teaching workspace. The source music notes record original synthesis with no third-party samples, recordings or melodies.

Rebuild with `python scripts/build_web_music.py` from the repository. Requires the original workspace source and ffmpeg. Export: MP3, 96 kbit/s, 120 seconds, 1,440,952 bytes; two-second entrance and four-second exit fades. Full decode verified with ffmpeg.

This small presentation asset is served with GitHub Pages. Large models and original media continue through the existing Drive workflow. The viewer assigns the audio URL only when Play music is pressed, defaults to 30% volume, and does not autoplay. Looping includes a deliberate gentle fade rather than a seamless musical join.
