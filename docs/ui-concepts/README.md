# UI concept references

These three generated concept images are design references for the shared training shell. They are not source-of-truth engineering illustrations and should not be embedded as evidence for component geometry, operating timing or gas behaviour.

| Reference | Intended influence |
|---|---|
| `explore-mode-reference.png` | Model-first desktop composition, compact mode navigation, clear inspection and section controls. |
| `learn-mode-reference.png` | Prediction-before-reveal lesson rail, step progress, 720-degree stroke context and prominent illustrative-cue disclosure. |

The implemented shell uses the common direction: persistent Explore/Learn/Check header tabs, shared Settings/About overlays, a main 3D region with a contextual control pane, and a narrow-screen layout that keeps the model above the controls. Treat generated typography and exact measurements as mockup-only; use the current web implementation and lesson contracts for production wording and behaviour.
