## What this report does not show

- The R10 part-spec with all 1,396 parts is a build output outside Git, so feature classes cover only the foundation parts whose spec is kept. Pass the full spec to extend it.
- No structured interface ledger exists: the inventories keep interfaces as free text, so the nearest structured record, the mechanism paths of the inventory, is used. Pairs closer than the clearance limit are not in any record (the audit counts neighbouring pairs but does not list them); listing them is the next step for the audit.
- The mass-check signal is membership of a line, not sensitivity: a line is checked to 15 percent, so a small part in a line can change without moving the check. Per-part volumes would let the signal weigh by share; they are not kept in Git.
